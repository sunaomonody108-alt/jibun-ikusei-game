# 自分育成ゲーム（最小版）

現実の行動を記録すると、自分の分身（相棒）が育つスマホ向けWebアプリです。

## ルール
- 毎日の最低ラインは「2分だけやった」1つ。これで今日は達成です。
- 記録ゼロで終わった日は、今週の経験値が20減ります。ただし今週稼いだ分の20%が上限です。
- ペナルティを受けた後の行動は、取り戻すまで経験値2倍です。
- レベルは絶対に下がりません。
- 今週の経験値がボス（HP300）へのダメージになります。
- 「週のまとめ」はコピーして人に送れます。

## 行動とポイント（game.js の ACTIVITIES で変更できます）
| 行動 | 単位 | XP | 能力 |
| --- | --- | --- | --- |
| 読書 | 1ページ | 1（専門書1.5倍） | 知力 |
| 勉強 | 1セッション | 20 | 知力 |
| ランニング | 1分 | 1 | 体力 |
| 料理 | 1回 | 15 | 生活力 |
| 間食しなかった | 1日 | 10 | 意志力 |
| 2分だけやった | 1回 | 5 | 選んだ行動の能力 |

## 動かし方
ビルドは不要です。フォルダを静的サイトとして公開すれば動きます（例: GitHub Pages）。
データは端末のブラウザ内（localStorage）に保存されます。
