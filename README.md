# 自分育成ゲーム（最小版）

現実の行動を記録すると、自分の分身（相棒）が育つスマホ向けWebアプリです。

## ルール
- 毎日の最低ラインは「2分だけやった」1つ。これで今日は達成です。
- 記録ゼロで終わった日は、今週の経験値が20減ります。ただし今週稼いだ分の20%が上限です。
- ペナルティを受けた後の行動は、取り戻すまで経験値2倍です。
- レベルは絶対に下がりません。
- 今週の経験値がボス（HP300）へのダメージになります。
- 「週のまとめ」はコピーして人に送れます。

## 行動とポイント（game.js の ACTIVITIES で変更できます）
| 行動 | 単位 | XP | 能力 |
| --- | --- | --- | --- |
| 読書 | 1ページ | 1（専門書1.5倍） | 知力 |
| 勉強 | 1セッション | 20 | 知力 |
| ランニング | 1分 | 1 | 体力 |
| 料理 | 1回 | 15 | 生活力 |
| 間食しなかった | 1日 | 10 | 意志力 |
| 2分だけやった | 1回 | 5 | 選んだ行動の能力 |

## 動かし方
ビルドは不要です。フォルダを静的サイトとして公開すれば動きます（例: GitHub Pages）。
データは端末のブラウザ内（localStorage）に保存されます。

## ごほうびショップ
現実のごほうび（例: 欲しかった本を買う）と、解放するレベルを自分で登録します。
そのレベルに届くと「つかう」ボタンが出ます。

## ものがたり（story.js）

- 怠けのモンスターが「未来の自分」の記憶をうばった、という設定です。はじめて開いたときに一度だけ話が流れます。
- 週のボスを倒すと「記憶のかけら」が1つもどります。中身は未来の自分への問いで、答えを書いておけます（あとから書いても、書きかえてもOK）。10個集めると、1年後の目標を1行で書く問いになります。
- 倒せなかったボスは次の週も残り、HPが10%ずつ上がります（最大+30%、名前に★）。
- ボス5体で1章です。新しい章に入ると、章の話が一度だけ流れます。

## 行動（わざ）の追加
「たたかう」→「＋ 行動を追加」から、自分の行動を追加できます。
経験値は自由に決めず、記録のしかたを3つの型から選びます（点数の水増しを防ぐため）。

| 型 | 経験値 |
|---|---|
| 時間 | 1分 1XP |
| 回数 | 1回 15XP |
| 1日1回 | 1日 10XP |

削除しても、これまでの記録と経験値は残ります。

## まんべんなくボーナス
戦闘画面の下に、今日きたえた能力（知力・体力・生活力・意志力）が出ます。
1日のうちに4つすべてをきたえると「パーフェクトデイ」になり、+30XPのボーナスが入ります。「2分だけ」はこの判定に数えません。
わざの一覧では、今日やった行動に ✓ が付き、まだの能力の行動は赤い枠で表示されます。

## 毎日の通知（カレンダー）
「ステータス」→「⏰ 毎日の通知を入れる」で時間を選ぶと、毎日くり返す予定（.ics）ができます。スマホのカレンダーに追加すると、その時間に通知が来ます。
アプリにはサーバーがないので、やった日にも通知は来ます。
